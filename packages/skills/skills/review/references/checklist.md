# Code Review Checklist

评审时逐项检查。**不要机械勾选**——只报告真实发现的问题。

## 正确性

- [ ] 边界条件（空数组、null、undefined、0、负数）
- [ ] 错误处理（异常捕获、返回值检查）
- [ ] 并发/竞态（如涉及）
- [ ] 类型安全（是否用了 `any`、类型断言）

## 安全

- [ ] SQL 注入（字符串拼接查询）
- [ ] 命令注入（`exec` / `spawn` 未转义）
- [ ] 路径穿越（`..` 未校验）
- [ ] XSS（未转义 HTML）
- [ ] 敏感信息泄漏（日志、错误消息）

## 性能

- [ ] N+1 查询
- [ ] 循环内不必要的分配
- [ ] 缺失索引（如涉及数据库）
- [ ] 大对象不必要的复制

## 可读性

- [ ] 命名是否表达意图
- [ ] 函数是否过长
- [ ] 是否有魔法数字
- [ ] 注释是否解释"为什么"而非"是什么"

## 严重程度分级

| 级别 | 定义 | 示例 |
|---|---|---|
| **high** | 会导致安全漏洞、数据丢失、服务中断 | SQL 注入、未捕获的异常 |
| **medium** | 会导致 bug 或性能问题 | 边界条件未处理、N+1 查询 |
| **low** | 影响可维护性，不影响功能 | 命名不清、缺类型标注 |
