# Evidence Template

排查结论的证据链模板。**每条证据必须有 文件:行号**。

## 格式

```
## 结论
<一句话直接回答>

## 证据
- <文件>:<行号> — <这条证据说明什么>
- <文件>:<行号> — <这条证据说明什么>

## 建议
<具体可执行的建议>

## 未能确认的信息
- <无法获取的部分> — <原因>
```

## 证据质量标准

| 级别 | 标准 | 示例 |
|---|---|---|
| **强** | 文件:行号 + 具体代码片段 | `packages/tools/src/read-file.ts:23 — 使用 path.relative 校验，拒绝 .. 逃逸` |
| **中** | 文件:行号 + 描述 | `packages/core/src/index.ts:5 — 无数据库导入` |
| **弱** | 仅描述，无行号 | `项目里没有 SQL`（**不用**） |

## 反模式

**不要写**：
- "看起来没有"（不够确定）
- "应该是"（需要证据）
- "我猜"（不专业）

**要写**：
- "全仓检索 X 返回 0 匹配"
- "文件 A 第 N 行的实现是 Y"
- "无法确认 X，因为 Y"

## 检索饱和的判断

连续 2 次 `search_code` 满足以下**任一条件**，判定为饱和：

1. 返回的文件集合与上次**高度重叠**（> 80%）
2. 返回**空结果**
3. 命中数**没有增长**

饱和后**停止搜索**，基于已有信息给结论。
