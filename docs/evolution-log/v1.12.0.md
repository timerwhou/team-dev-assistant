# RFC: v1.12.0 — 能力生态与多 Agent 协同

## 1. 产品定论 (Product)
- **版本主题**：能力生态与多 Agent 协同（Agent Ecosystem & Orchestration）。
- **核心升级**：
  1. **零门槛冷启动**：`/init` 利用 AST 静态分析与 AI 辅助，在零标注的老项目中低成本生成 Playbook 草案。
  2. **生产级触发**：Webhook 触发机制，配合 HMAC-SHA256 验签，融入真实 CI/CD 与业务流。
  3. **生态与可视化**：支持多级 Domain 标签，提供“能力工厂”让非技术人员发布能力；同时提供图/列表双视图的多 Agent 协同看板，支持 HITL。

## 2. 技术架构 (Tech Spec)
- **Schema 扩展**：
  - `CapabilityMetadata` 增加 `publisher: string` 和 `domain: string[]`。
  - `WorkflowManifestSchema` 增加 `triggers` 字段。
- **核心模块**：
  - CLI 新增 `/init`。
  - 后端新增 Webhook 验签中间件与 `/api/webhooks/:token`。
  - 前端新增 Capability Studio（低代码注册）与 A2A Dashboard（双视图观测）。

## 3. 架构守护 (Governance)
- 所有 Schema 扩展保持向后兼容（默认值兜底）。
- 引入能力沙箱，防止第三方低代码能力越权访问。
- 更新 Fitness 测试，确保新增模块不破坏既有分层架构。
