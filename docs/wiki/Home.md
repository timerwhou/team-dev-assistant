# Team Dev Assistant

AI Agent monorepo —— 代码评审、问题排查、Issue 汇总。

## 文档导航

- [[Architecture]] — 架构设计与技术决策
- [[Demo]] — 3 分钟演示脚本
- [[Resume]] — 简历素材与面试 Q&A

## 快速开始

```bash
git clone https://github.com/timerwhou/team-dev-assistant.git
cd team-dev-assistant
pnpm install
cp .env.example .env
pnpm dev "/review apps/cli/src/index.ts"
```
